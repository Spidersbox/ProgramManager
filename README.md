<b>This is a clone of the old windows Program Manager</b><br>
<br>
Create groups to help organize your icon shortcuts.<br>
Drag and drop files, folders, images, apps, etc .. from desktop or file explorer.<br>
<br>
Note: The Program Manager only holds links/shortcuts.<br>
      Do not drag a folder to the Program Manager, and delete the folder!<br>
      (or anything else for that matter)<br>
<br>
Tested on Ubuntu 22.04 and windows 10/11<br>
