<b>This is a clone of the old windows Program Manager</b><cr>
<cr>
Create groups to help organize your icon shortcuts.<cr>
Drag and drop files, folders, images, apps, etc .. from desktop or file explorer.<cr>
<cr>
Note: The Program Manager only holds links/shortcuts.<cr>
      Do not drag a folder to the Program Manager, and delete the folder!<cr>
      (or anything else for that matter)<cr>
<cr>
Tested on Ubuntu 22.04 and windows 10/11
